# AapniSociety 0.0.1 Release Notes

Date: 2026-06-17
Status: Complete

## Release Goal

`0.0.1` is the recovery baseline for AapniSociety.

It does not ship runnable modern software. It establishes what the old project was, what we are rebuilding, why the old implementation should remain archival, and what `0.1.0` must build first.

## What Changed

- Added the long-form scope and concept note.
- Added the formal software requirements specification.
- Added the maintained roadmap.
- Added the legacy audit of the Android client and Django server.
- Reframed the product around worker-led, worker-owned cooperative infrastructure.
- Identified `0.1.0` as the Cooperative Trust Pilot.

## Legacy Findings

The Android client contains the richer product memory:
- service requests
- service-provider suggestions from contacts
- neighborhood places
- geotagging
- gossip/community messages
- local trust transfer

The Django server repo is incomplete relative to the Android client:
- only `/register/` is wired in checked-in URLs
- the Android app calls several other endpoints
- the checked-in database has no meaningful domain seed data

## Rebuild Decision

The old implementation should not be revived directly.

Reasons:
- legacy Android/ADT project
- hardcoded HTTP backend URLs
- broad permissions around contacts, SMS, and location
- hardcoded maps key
- outdated Django server
- weak checked-in server functionality
- privacy model unsuitable for 2026

The rebuild should preserve concepts, not code.
